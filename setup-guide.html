Step 01 · ~3 min

Open sheets.google.com — make sure you're in the Gmail account you'll use for Apps Script

3
Do this 4 times — one for Master, one for each of the 3 branches
4
From each sheet URL, copy the Sheet ID — it's the long string between /d/ and /edit

2
Step 02 · ~2 min
Create the Apps Script
Create project
1
Go to script.google.com — sign in with the same Gmail account
2
Click New Project (top left)
3
Click the title "Untitled project" at the top → rename it to Green Salon
4
In the editor, select all the existing code (Ctrl+A) → delete it
5
Open the Code.gs file you downloaded → copy everything → paste into the editor
6
Press Ctrl+S (or click 💾 Save) — the project name shows in the tab
3
Step 03 · ~2 min
Paste Your Sheet IDs
Find these lines at the top of Code.gs
// REPLACE these 4 values with your actual IDs from Step 1 const MASTER_SHEET_ID = "MASTER_SHEET_ID_HERE"; const BRANCH_SHEETS = { "branch1": "BRANCH1_SHEET_ID_HERE", // JC Nagar "branch2": "BRANCH2_SHEET_ID_HERE", // Koramangala "branch3": "BRANCH3_SHEET_ID_HERE", // Indiranagar };
Replace each placeholder with your real ID
1
Delete "MASTER_SHEET_ID_HERE" → paste your Master sheet ID inside the quotes
2
Delete "BRANCH1_SHEET_ID_HERE" → paste your JC Nagar sheet ID
3
Repeat for branch2 and branch3
4
Optionally change the OWNER_PASSWORD on line 28 to something personal
5
Press Ctrl+S to save
💡
IDs go inside the quotes. The quotes themselves must stay. Example: "1BxiMVs0XRA5nFMdKv..."
4
Step 04 · ~3 min
Run Setup Functions
Run firstTimeSetup
1
In the Apps Script editor, find the function dropdown near the top toolbar — it shows a function name
2
Click the dropdown → select firstTimeSetup
3
Click ▶ Run
4
A permissions dialog appears — click Review permissions → choose your Gmail → click Allow
5
Wait for "Execution completed" to appear at the bottom of the screen
Run setupTriggers
1
Same dropdown → select setupTriggers → click ▶ Run
2
Wait for "Execution completed" — this creates 4 daily auto-jobs
⚠️
Don't skip permissions. If you see "Authorization required", click it and allow everything. Without this, the app cannot read/write Google Sheets.
Verify it worked
✓
Open your Master Google Sheet — you should see 3 new tabs: Branches, Settings, AdminLog
✓
Open a branch sheet — you should see tabs: Staff, Services, Products, Entries, Expenses, Reports, Daily, May 2026
5
Step 05 · ~2 min
Deploy & Get Your URL
Deploy as Web App
1
Click Deploy button (top right) → New deployment
2
Click the ⚙ gear icon next to "Select type" → choose Web app
3
Description: type anything, e.g. Green Salon v1
4
Execute as: Me
5
Who has access: Anyone — not "Anyone with Google account"
6
Click Deploy → copy the URL that appears
Your URL looks like this
https://script.google.com/macros/s/AKfycbx.../exec
https://script.google.com/macros/s/AKfycbxLongRandomStringHere/exec

↑ Save this URL. You'll paste it in both apps.
🔴
Must end with /exec — not /dev. The /dev URL is only for testing inside the editor and will fail in the app.

Step 07 · ~1 min
Set Up Staff App on Tablet
Open and connect
1
Open staff-app.html on the tablet browser (Chrome recommended)
2
Paste your /exec URL in the setup screen
3
Select the branch for this tablet (e.g. JC Nagar → branch1)
4
Tap Connect & Open App — staff cards appear
Install as PWA (Add to Home Screen)
1
In Chrome, tap the ⋮ menu (three dots, top right)
2
Tap "Add to Home screen" or "Install app"
3
Tap Install — a Green Salon icon appears on the home screen
4
Open from that icon — it runs fullscreen with no browser bar ✓
📱
On iOS Safari: tap the Share icon (box with arrow) → Add to Home Screen. Works the same way.
